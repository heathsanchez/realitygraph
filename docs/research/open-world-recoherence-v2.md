# Open-World Recoherence V2 — Residual-Generated Meta-Schema

## Purpose

V1 integrated UNKNOWN preservation, structural growth, capability compilation,
prospective reuse, exact restart, revocation, and requalification in one persistent
developmental stream, but it still supplied a named repair portfolio:

- ADD_LOGIC
- ADD_TEMPORAL

V2 removes that named portfolio.

The controller receives no named logical, temporal, memory, delay, XOR, AND, OR,
or previous-state repair family. After complete current-language failure under
closed authority, the residual licenses one generic meta-construction:

> build the smallest exact finite deterministic realizer over the raw encounter
> coordinates, ordered by state count and input arity.

The winning structure is therefore determined by verifier consequence, not by a
pre-selected repair label.

Branch:

`qckn-open-world-recoherence-v2-meta-genesis`

Base:

`qckn-open-world-recoherence-v1`

## Frozen boundary

The supplied lower meta-substrate is deliberately small and explicit:

- two opaque raw encounter coordinates;
- finite ordered encounter histories;
- exact external verifier;
- deterministic finite realizers with at most three internal states;
- exhaustive enumeration in increasing state count and input arity.

There is no list of domain-level repair families.

This remains bounded meta-substrate genesis, not construction from nothing.

## Developmental sequence

The stream is frozen before execution.

### E0 — incomplete authority

A partial positive observation episode is deliberately left open.

Result required:

`UNKNOWN`

No meta-schema or capability may be promoted.

### E1 — direct present consequence

The target is already in the current projection language.

No structural growth is licensed.

### E2 — residual-generated meta-schema

The target is a two-coordinate conjunction.

The complete current language contains only constants and current-coordinate
projections, so the target is absent.

That exact no-resolution result licenses generation of the generic finite-realizer
schema. Exhaustive search then finds a two-state, two-input realizer. Its verified
one-step behavior is compressed into a coordinate-free binary behavioral macro.

Critically, the controller was not supplied an `AND` primitive or a
`LOGIC` repair family.

### E3 — prospective behavioral reuse

The same binary behavior is required under a coordinate-order variation.

The retained behavioral capability should reduce verifier search relative to the
matched cold twin.

### E4 — same schema, stateful structure

A new target depends on an earlier encounter value and therefore cannot be
represented by the current projection language.

The same previously generated finite-realizer schema is reused. The exact search
must synthesize a realizer with more than one state.

No separate temporal/memory repair family is introduced.

### E5 / E6 — cross-substrate composition

The retained stateful realizer creates a derived historical feature. The previously
compiled binary behavioral macro composes that feature with a current feature.

E6 additionally requires coordinate remapping of the retained stateful capability.

Both episodes have matched cold endpoints; the cold twin can still solve them by
fresh finite-realizer search, but should pay more verification work.

## Controls

### WARM

Persistent generated schema and verified capabilities remain active.

### COLD

Every episode restarts from the original language and must re-earn structural
growth and capabilities while using the same verifier and bounded meta-substrate.

### CAPABILITY_ABLATION

The generated schema persists, but every accumulated executable capability is
deactivated before the next episode.

### SCHEMA_ABLATION

The E2 residual is exposed with no permission to instantiate the generic
meta-schema. The episode must remain obstructed.

### AUTHORITY SHIFT

After exact restart, authority changes from A1 to A2.

All A1 capabilities are deactivated. Their contracts are requalified under A2
before becoming active again. A post-shift episode then tests reuse under the new
authority.

## Required gates

V2 passes only if:

1. open evidence stays UNKNOWN;
2. no named extension portfolio is present;
3. a complete residual generates the generic realizer schema;
4. a stateless behavioral macro is compiled;
5. later behavioral reuse is cheaper than cold;
6. the same generated schema synthesizes a stateful realizer;
7. cross-substrate composition is cheaper than cold;
8. remapped cross-substrate composition is cheaper than cold;
9. the matched cold twin still reaches the same VERIFIED/UNKNOWN endpoints;
10. aggregate WARM cost is lower than COLD;
11. capability ablation loses the warm advantage;
12. schema ablation restores the obstruction;
13. snapshot/restart is exact;
14. stale capabilities are revoked after authority change;
15. requalification restores active capability only under the new authority;
16. post-shift reuse verifies.

## Warranted claim if green

A PASS would establish:

> In a frozen bounded encounter world, complete current-language failure can
> generate a generic finite-realizer meta-schema without choosing from a named
> repair portfolio; verifier consequence can then select both stateless and
> stateful realizations from that schema, compile them into reusable capability,
> compose them across later episodes, and produce lower verifier work than a
> matched cold twin while preserving UNKNOWN, restart, revocation, and authority
> boundaries.

## What remains after V2

V2 still supplies the universal finite-realizer schema itself as the lower
meta-substrate.

The next wall becomes sharper:

developmental languages, not only the object-level language.
