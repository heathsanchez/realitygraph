# Open-World Recoherence V4 — Live External Producer Attachment

## Purpose

V3 derives new node input geometry directly from verified residual structure in a
bounded encounter world. V4 moves that qualified developmental kernel into the
same scheduled runtime cycle as the real persistent Flash producers.

V4 is deliberately an **attachment precursor**, not yet the final causal claim
that the V3 schema compiler chooses the real Lean / ARC / Collatz / SAIR
experiments.

The goal is narrower:

> one scheduled process should requalify the current residual-derived
> developmental constitution, ingest fresh independently emitted events from
> source-distinct repositories, reclose the persistent RealityGraph state, retain
> past state across cold workflow starts, and emit one combined manifest binding
> the developmental kernel version to the actual external producer heads.

Branch:

`qckn-open-world-recoherence-v4-live-attachment`

## Developmental constitution

The same cycle checks out:

`qckn-open-world-recoherence-v3-residual-schema-genesis`

and requires:

`PASS_OPEN_WORLD_RECOHERENCE_V3_RESIDUAL_SCHEMA_GENESIS`

before accepting the cycle as V4 evidence.

This gives the live cycle an explicit developmental constitution:

- incomplete authority preserves UNKNOWN;
- no named repair portfolio;
- no supplied candidate node family;
- minimum residual-derived interface shape;
- compilation and reuse;
- exact restart;
- revocation and authority requalification.

## Persistent live graph

V4 separately checks out the qualified persistent router:

`qckn-flash-live-router-v3`

It recovers the latest non-expired V4 state artifact when available, discovers
all current producer `event.json` outboxes, ingests them, and writes the next
compiled present.

The cycle therefore preserves the existing Flash properties:

- new-event-only advancement;
- retained compiled past;
- active capability / obstruction state;
- dependency-aware reclosure;
- cold workflow restart from the previous compiled present.

## Combined manifest

Each successful cycle writes:

`open-world-v4-manifest.json`

containing:

- V3 kernel verdict;
- V3 protocol digest;
- exact producer HEAD SHAs;
- live RealityGraph summary;
- newly seen event IDs;
- unchanged event IDs;
- retained past event IDs;
- a digest of the combined record.

This prevents later claims from silently combining a developmental result from
one revision with external producer events from another.

## Scientific boundary

A V4 PASS establishes runtime attachment, not full open-world self-directed
development.

Specifically, V4 does **not yet** show that:

- a live domain residual is handed to the V3 residual-schema compiler;
- the compiler invents a new real experiment or action family;
- that invented experiment is executed against the source repository;
- the returned real evidence is admitted and globally reclosed;
- the compiled result reduces later real work.
