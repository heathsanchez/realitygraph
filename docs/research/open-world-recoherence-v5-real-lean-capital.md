# Open-World Recoherence V5 — Real Lean Developmental Capital

## Why V5 exists

The branch audit exposed a major correction to the synthetic V1–V4 ladder:

the real Lean-kernel repo had already pushed several of the supposedly future
developmental mechanisms into source-distinct held-out experiments.

In particular:

- V26 removes the supplied action menu and tests endogenous measurement-closure genesis;
- V38 blindly selects a shared retained kernel interface before held-out Std/Cedar economics;
- V40 recursively acquires a second native interface from a post-first-interface residual;
- V40 earned-memory selects how an acquired interface should be deployed using acquisition-side deterministic economics, then evaluates the frozen policy on fresh continuations.

V5 therefore does not invent another synthetic analogue.

It turns those existing successful real-world developmental results into typed,
persistent RealityGraph capital.

## Fail-closed evidence harvesting

V5 does not trust branch names or documentation as proof.

For each lane it queries GitHub Actions for the latest **successful** workflow run
on the exact source branch, downloads the expected non-expired artifact, and
requires the exact terminal scientific marker inside `result.txt`.

The four required lanes are:

| lane | source branch | required marker |
|---|---|---|
| V26 | `msikernel-endogenous-closure-genesis-v26` | `ENDOGENOUS_CLOSURE_GENESIS_V26=BOUNDED_POSITIVE` |
| V38 | `msi-blind-kernel-interface-genesis-v38` | `DECISION=BLIND_INTERFACE_GENESIS_TRANSFER` |
| V40 recursive | `msi-recursive-interface-genesis-v40` | `V40_DECISION=RECURSIVE_NATIVE_INTERFACE_GENESIS_TRANSFER` |
| V40 memory | `msi-earned-memory-policy-v40` | `DECISION=EARNED_MEMORY_POLICY_TRANSFER` |

If a successful run, artifact, or marker is unavailable, V5 fails closed and
admits nothing.

## Typed developmental capabilities

Each validated artifact is converted into a canonical
`qckn-flash-external-event-v1` capability event.

The source evidence bytes are hashed into the event envelope.

The authority snapshot binds:

- source repository;
- exact workflow head SHA;
- source branch.

The certificate binds:

- workflow run ID;
- artifact ID;
- artifact name;
- required terminal marker.

The four resulting meta-capabilities represent:

1. **endogenous closure generation**;
2. **blind shared-interface acquisition with held-out economic causality**;
3. **recursive second-interface genesis**;
4. **earned deployment policy for retained memory**.

They are stored as developmental capabilities, not as claims that arbitrary Lean
problems are solved by them.

## Persistent reclosure

The harvested events are fed through the existing qualified
`qckn-flash-live-router-v3`.

V5 recovers the previous V5 `state-bundle.json` artifact when one exists, so
repeated workflow executions are incremental rather than replay-from-zero
research episodes.

The resulting artifact therefore binds real external developmental evidence into
the same persistent capability / obstruction / provenance machinery used by
RealityGraph.

## What V5 deliberately does not claim

The four source experiments were historically separate.

V5 therefore does **not** relabel them as one prospectively frozen causal chain.

It also does not yet allow RealityGraph to:

- select the next live Lean residual;
- construct the next Lean experiment;
- dispatch that experiment;
- ingest its result;
- measure whether the newly compiled developmental capital reduced later real work.

That is the remaining V6 step.
