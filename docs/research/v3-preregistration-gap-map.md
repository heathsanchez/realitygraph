# V3 → A/B/G/P preregistration gap map

## Purpose

This note prevents pilot/developmental evidence from being accidentally counted as confirmatory evidence.

`verified-meta-growth-v3` is compared here against the current A/B/G/P joint-study design. V3 was built before the confirmatory study is frozen and therefore cannot count as a confirmatory pass for any arm. The useful question is narrower:

> Which mechanisms and controls already exist, and which scientific separators remain genuinely untested?

The confirmatory study must still use fresh frozen task families/seeds, fixed interaction budgets, frozen verifier/model hashes, predeclared margins, and the jointly frozen analysis rule.

## A — verifier channel

**Preregistered target:** a non-identifying verifier residual improves protected action selection beyond equal-compute reconsideration. For every constructor-visible message class, the permitted message must leave more than one protected action compatible with the constructor's information.

### What V3 already supplies

- explicit authority and verifier identity in obstruction fingerprints;
- stale-authority and stale-verifier rules are rejected;
- incomplete evidence cannot masquerade as a structural result;
- the constructor/meta-policy cannot promote a repair from partial search;
- proposal, authority, and retained developmental permission remain separated.

### What V3 does not test

- no preregistered constructor-visible message alphabet;
- no direct-action-insufficiency calculation `|A*(m)| > 1`;
- no one-shot vs equal-compute recheck comparison;
- no graded verifier-channel experiment;
- no test that improvement survives when verifier messages are provably non-identifying.

### Status relative to A

`MECHANISM_READY / CONFIRMATORY GAP OPEN`

V3 strengthens the implementation boundary needed by A, but provides no A PASS evidence.

## B — grammar invariance

**Preregistered target:** recover the same protected future-action class across independently parameterised relation grammars whose primitives, arity, composition rules, inference paths, surface symbols, and serialization are generated independently. Only the latent task/world generator and protected action-order semantics may be shared. Success is behavioral agreement on held-out interventions, not literal relation reconstruction.

### What V3 already supplies

- exact obstruction fingerprints invariant to surface relabeling;
- non-isomorphic obstruction structures receive different fingerprints;
- incidence multiplicity is preserved;
- two genuinely different obstruction families learn different repair classes;
- acquisition/calibration/future variants use disjoint surface carriers within a family while preserving the same exact structural fingerprint;
- wrong-fingerprint reuse is rejected.

### What V3 does not test

- independently generated relation grammars with different primitives and arities;
- independently different composition/inference routes;
- absence of a hidden primitive dictionary across grammar families;
- acquisition under one grammar and recovery under another;
- held-out structural interventions that change protected action ordering;
- matched-complexity wrong-class and shuffled-coupling separators at the cross-grammar level.

### Status relative to B

`WEAKER INVARIANCE PRECURSOR / STRONG B GAP OPEN`

V3 establishes canonical structural matching beyond literal names, but it is intentionally weaker than the preregistered cross-grammar claim.

## G — corruption dose-response

**Preregistered target:** downstream behavior should track corruption of distinctions capable of changing protected action order. The primary confirmatory test is the predeclared relevance × corruption-dose interaction, supplemented by exact action-order flip rate.

### What V3 already supplies

- retained objects and repair rules have explicit structural scope and exact identities;
- attacks and protected future checks can be used as evaluation endpoints;
- fail-closed controls are already available when evidence no longer warrants reuse.

### What V3 does not test

- action-relevant versus action-irrelevant cell classification;
- graded corruption doses;
- matched corruption magnitude/count controls;
- relevance × dose interaction;
- action-order flip rates under corruption;
- dose-response monotonicity.

### Status relative to G

`INFRASTRUCTURE ONLY / CONFIRMATORY GAP OPEN`

V3 should not be interpreted as G evidence.

## P — persistence form

**Preregistered target:** a verifier-induced non-verbal structural object transfers on source-distinct future tasks without verifier feedback, beats cold/equal-compute/sham controls, and loses the gain under targeted ablation.

A subsequently agreed stronger persistence boundary adds:

- compile/serialize the retained object;
- hard restart from only retained state;
- select later applicability without target labels;
- zero reconstruction/search on untouched future groups;
- no verifier on the future transfer path;
- targeted deletion restores the cold baseline and reacquisition search.

### What V3 already supplies

- exact canonical serialization of object state plus meta-memory;
- byte-exact cold restart without fixture or strategy objects;
- future obstruction matching uses the retained promoted meta-rule;
- future repair-family selection uses zero repair-portfolio search;
- future competitor strategy calls are zero;
- future object-level grammar search is zero after the retained repair class is selected;
- future capability IDs differ from acquisition capability IDs, so the system is not merely replaying the old task solution;
- targeted deletion of the retained meta-rule restores cold portfolio search and rediscovery;
- applicability is guarded by exact obstruction, portfolio, authority, verifier, and interface identity.

### What V3 does not test

- future transfer with the verifier entirely removed;
- source-distinctness at the full preregistered strength (identifiers, lexical templates, seeds, serialization, and exact topology all disjoint);
- comparison against equal-compute recheck and size-matched sham retained objects on the primary action metric;
- hard restart from *only* the retained object if object-capability synthesis still relies on live verification infrastructure;
- no-verifier causal transfer of the retained structural object itself.

### Status relative to P

`STRONG PERSISTENCE MECHANISM / FULL P GAP OPEN`

V3 is the closest arm to P, but it does not satisfy the decisive no-verifier future boundary. It should be treated as pilot/methodological evidence for how to implement P, not as a P PASS.

## What V3 uniquely contributes to the joint study

V3 makes one additional distinction explicit that is useful across all four arms:

    object capability acquisition
        != developmental repair-family acquisition
        != promotion after independent calibration
        != persistence across restart
        != future applicability selection
        != construction of the next task-specific capability

The confirmatory study can therefore instrument these stages separately rather than treating "learning" as one event.

It also provides exact failure routes:

- incomplete current language → `UNKNOWN_SEARCH`;
- incomplete repair portfolio → `UNKNOWN_SEARCH`;
- equally justified repair classes → `UNKNOWN_CHOICE`;
- stale/wrong boundary → retained rule cannot fire;
- no successful repair in a complete portfolio → named bounded meta-obstruction.

## Clean confirmatory boundary

Nothing in V3 should consume the fresh A/B/G/P questions.

The next confirmatory implementation should therefore **reuse the constitutional machinery but replace the V3 qualification worlds** with fresh frozen study generators. In particular:

- A should add the non-identifying channel audit and equal-compute comparator;
- B should supply four genuinely independently parameterised grammar families and structural interventions;
- G should add the frozen relevance classifier and graded corruption schedule;
- P should use the hard retained-only restart, label-free applicability, no-verifier future path, matched controls, and targeted deletion.

A future all-arm pass would license only the preregistered bounded interpretation: a non-identifying verified residual can induce a decision-sufficient behavioral class that is representation-robust within the tested grammar family, corruption-sensitive in the predicted action-relevance sense, and persistently reusable without the verifier on source-distinct future tasks.

It would still not establish representation-independent invention, universal grammar invariance, open-ended ontology construction, or unbounded self-development.
