# Open-World Recoherence V1

## Status

This branch is the first integrated precursor to the larger open-world developmental test.

It is intentionally **not** presented as the final natural-world closure experiment. Its purpose is to put the previously separate mechanisms into one prospectively frozen executable stream and test whether they coexist causally without weakening the epistemic boundary.

Branch:

`qckn-open-world-recoherence-v1`

Base:

`qckn-live-developmental-substrate-v3-frozen`

## Question

Can one persistent developmental state:

1. preserve UNKNOWN when authority is incomplete;
2. certify no-resolution in its current language before structural growth;
3. grow a missing logical operator family;
4. compile a verified behavioral capability;
5. reuse that capability prospectively;
6. grow a missing temporal substrate later;
7. compose the retained capability across the enlarged substrate;
8. beat a matched cold twin;
9. lose that advantage under capability ablation;
10. restart exactly;
11. revoke stale capability at an authority change; and
12. requalify and reuse only under the new authority?

All of those gates are exercised in one deterministic stream.

## Frozen developmental substrate

The initial active language contains only:

- constants;
- two current-signal observables.

It does **not** initially contain:

- NAND;
- previous-state observables;
- compiled binary behavioral macros.

The declared bounded extension portfolio contains two generic substrate moves:

- `ADD_LOGIC`: add NAND as a generic Boolean combiner;
- `ADD_TEMPORAL`: add previous-signal terminals.

These are intentionally still supplied families. V1 therefore does not establish unrestricted substrate invention.

## Stream

The prospective stream contains:

- an open-authority episode that must remain UNKNOWN;
- a directly expressible target;
- a binary target that requires logical-language growth;
- a later equivalent target that should benefit from the compiled behavioral macro;
- a temporal target that requires substrate growth;
- a mixed temporal/current target that can reuse the retained binary macro;
- a derived mixed composition;
- an authority transition followed by stale-capability revocation and requalification.

The controller does not promote from `CONSISTENT_ONLY` evidence. Only closed external verification can produce an active capability.

## Behavioral capability compilation

When a verified result depends on exactly two independent signals, the result is compressed into its coordinate-free 4-row binary behavior table and stored as an executable macro under the current authority.

Future episodes can instantiate that behavior over any currently available pair of signals.

This makes the retained object a behavioral capability rather than an answer-memory record tied to the original surface coordinates.

## Matched controls

Three primary conditions are run over the same episode stream.

### WARM

Persistent language growth and compiled capabilities survive between episodes.

### COLD

Each episode restarts from the initial developmental state.

### MACRO_ABLATION

Structural language growth persists, but compiled behavioral capabilities are deactivated before each episode.

The endpoint verifier is identical in every arm.

## Gates

The workflow requires all of the following:

- protocol frozen before stream;
- UNKNOWN preserved under open authority;
- logic growth follows no-resolution;
- a behavioral capability is compiled;
- later reuse reduces search;
- temporal substrate grows when needed;
- cross-substrate composition compounds;
- derived composition compounds;
- aggregate WARM beats COLD;
- capability ablation loses the warm advantage;
- snapshot/restart is exact;
- authority change revokes stale capability;
- only requalified capability becomes active under the new authority;
- post-shift reuse remains cheaper than matched cold acquisition.

## Claim boundary

A PASS establishes only a bounded integration result.

The verifier semantics, finite signal universe, extension families, and episode generator remain supplied.

This V1 therefore does **not** establish:

- unrestricted natural-world self-development;
- arbitrary action-language invention from no declared meta-substrate;
- learned terminal authority;
- open-ended ontology growth;
- scale to large asynchronous multi-domain graphs.

Its role is narrower and necessary:

> show that UNKNOWN, warranted language growth, capability compilation, prospective reuse, substrate growth, causal ablation, exact restart, revocation, and requalification can coexist in one persistent developmental stream and produce measurable compounding against a matched cold twin.

The next escalation should replace the synthetic episode stream with external producer events while keeping this exact constitutional structure.
