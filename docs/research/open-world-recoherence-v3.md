# Open-World Recoherence V3 — Residual-Derived Node Schema

## Why V3 exists

V2 removed the named `ADD_LOGIC` / `ADD_TEMPORAL` repair portfolio, but still supplied one generic finite-transducer meta-substrate.

V3 removes that handhold too.

There is no supplied finite-state-machine family, logic family, memory family, delay family, or candidate node catalogue.

The residual compiler receives only:

- finite raw encounter coordinates;
- finite encounter order;
- closed verifier consequences when authority is complete;
- a maximum bounded history depth.

From that, it searches raw `(lag, coordinate)` subsets in increasing cardinality and asks:

> what is the smallest input geometry on which the protected consequence becomes a well-defined finite function?

The resulting extensional table is the generated node.

## Developmental stream

### E0 — epistemic floor control

Open positive evidence is insufficient for promotion.

Required result:

`UNKNOWN`

### E1 — direct consequence

Current-coordinate projection already suffices.

No genesis is licensed.

### E2 — binary node-schema genesis

The protected consequence is conjunction over two current opaque coordinates.

No supplied AND or Boolean-combiner family exists.

The residual search finds the minimum two-locus geometry:

[
{(0,c_0),(0,c_1)}
]

and compiles its four-row extensional behavior as a reusable binary macro.

### E3 — prospective reuse

The same behavioral relation is presented under coordinate-order variation.

The compiled binary behavior should be cheaper than re-deriving the node schema from cold state.

### E4 — historical node-schema genesis

The protected consequence depends on the previous value of one coordinate.

The current language and binary current-time macro cannot express it.

The same residual rule searches raw loci and discovers a one-locus historical geometry:

[
{(1,c_0)}.
]

That yields a generic lag-one unary capability, without a supplied `previous`, `delay`, `memory`, or state-machine primitive.

### E5 — cross-time composition

The retained historical feature is composed with a current feature through the already compiled binary behavior.

### E6 — remapped cross-time composition

The historical capability is reused on the other opaque coordinate and recomposed with the same binary macro.

## Controls

The exact same stream is run as:

- **WARM** — retain compiled capabilities;
- **COLD** — reset to the initial active language each episode;
- **CAPABILITY_ABLATION** — retain developmental history but deactivate executable capability before each next episode;
- **SCHEMA-COMPILER ABLATION** — expose the E2 no-resolution residual but forbid residual-derived node synthesis.

The cold arm must still reach the same `VERIFIED` / `UNKNOWN` endpoint classes.

## Exact boundary

V3 still assumes:

- finite opaque raw encounter coordinates;
- temporal order;
- bounded accessible history;
- a finite known consequence alphabet;
- exact closed authority when promotion is permitted;
- generic extensional finite-map compilation.

It therefore does not derive sensing, time, or authority from nothing.

The next meaningful escalation is no longer another synthetic node-family genesis experiment.

It is to attach this residual-derived schema compiler to **external producer events** and ask whether the same rule survives source-distinct, changing real workloads while RealityGraph performs persistent reclosure.

That is the bridge from bounded ontology genesis to the real open-world developmental loop.
