# Miller–Schupp centralizer recurrence

## Computational discovery

On the certified SAIR Miller–Schupp trajectories, the ordinary AC move macro

`[6, 2, 9, 3, 7]`

recurs as an exact reduction from the presentation with parameter `n + 1` to the presentation with parameter `n` throughout the pure-`y` families.

Using the SAIR encoding

- `A_n = x^-1 y^n x y^-(n+1)`
- `B_w = x w^-1`
- `P(n,w) = (A_n, B_w)`

the five frozen Discovery-track moves are:

1. `6`: conjugate the first relator by `x`;
2. `2`: right-multiply the first relator by the second;
3. `9`: conjugate the first relator by `y^-1`;
4. `3`: right-multiply the first relator by the inverse of the second;
5. `7`: conjugate the first relator by `x^-1`.

Starting from `P(n+1,w)`, exact free reduction gives

`A_(n+1)`
`-> y^(n+1) x y^-(n+2) x^-1`
`-> y^(n+1) x y^-(n+2) w^-1`
`-> y^n x y^-(n+2) w^-1 y`
`-> y^n x y^-(n+2) w^-1 y w x^-1`
`-> x^-1 y^n x y^-(n+2) w^-1 y w`.

Therefore the final first relator is exactly `A_n` whenever

`w^-1 y w = y`.

The second relator is unchanged throughout the macro. Hence:

> For every positive `n` and every free-group word `w` satisfying `w^-1 y w = y`, the presentation `P(n+1,w)` is Andrews–Curtis reachable from `P(n,w)` by the displayed macro (with inverse-relator multiplication expanded into primitive AC steps when using the official Proof-track `AC.Step`).

In particular, every power `w = y^k` satisfies the guard. In the free group on `x,y`, the centralizer of `y` is the cyclic subgroup generated by `y`, so this guard isolates exactly the pure-`y` family.
